Toda persona que aprende desarrollo web acaba acumulando preguntas: por qué una maquetación se rompe en móvil, cuándo conviene usar un framework o cómo se publica un sitio sin complicaciones. Este blog es mi forma de responder a esas preguntas y dejar constancia de lo que voy aprendiendo.

## Qué vas a encontrar

Escribiré sobre tres bloques principalmente:

- **Fundamentos:** HTML semántico, CSS moderno y JavaScript que se entienda.
- **Herramientas:** Astro, Git, GitHub Actions y todo lo que use en mis proyectos.
- **Proceso:** decisiones, errores comunes y pequeños trucos que me ahorran tiempo.

No pretendo ser un manual exhaustivo. Prefiero artículos cortos que respondan a una pregunta concreta y que puedan leerse en cinco minutos.

## Por qué Astro

Este sitio está construido con Astro porque genera HTML estático por defecto: no envía JavaScript al navegador salvo que lo pidas explícitamente. Eso se traduce en páginas rápidas y en una forma muy cómoda de escribir contenido en Markdown.

Un artículo se reduce a un archivo con unas pocas líneas de metadatos:

```markdown
---
title: 'Mi primer artículo'
description: 'De qué trata.'
pubDate: 'Nov 18 2026'
---

Aquí empieza el contenido.
```

## Te leo

Si encuentras un error o quieres que explique algo en particular, puedes abrir una incidencia en el repositorio del blog. Corregir una explicación también es parte de aprender.
